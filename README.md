# Insurance Claims Analysis Dashboard

**Excel Portfolio Project | Actuarial & Insurance Analytics**

**Objective:** Analyse a simulated insurance portfolio to evaluate claims performance, claims severity, claims frequency, loss ratios and outstanding claims.

**Dataset:** 500 policies and 250 claims (simulated)

**Tools:** Microsoft Excel, formulas, Pivot Tables, Pivot Charts, slicers and dashboard visualisation.

## Key skills demonstrated

- Insurance data organisation and analysis
- Claims frequency and severity calculations
- Loss ratio analysis
- Claims settlement and outstanding claims analysis
- Interactive dashboard development
- Data interpretation and reporting

## Key finding

Motor insurance recorded the highest loss ratio in the simulated portfolio, at 44%, while Property recorded the lowest, at 25%.
